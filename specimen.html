Setting Markdown to a book standard

Every element below is plain Markdown output. No element has been hand-adjusted for this page; the whole difference between this and a browser default is the stylesheet. The measure is capped at the container level so that tables, figures and code can break out of it while running text stays inside — the single structural decision most default renderers get wrong.

The two themes are token sets over one component layer. Switching theme changes the palette, the faces, the measure and a handful of structural devices; it does not change the markup, and it does not change which components exist.

Headings and depth

Below level three, depth is signalled by a change of style rather than a further reduction in size. Six sizes is a ramp nobody can read; three sizes plus italic and small caps is a hierarchy anyone can. Space above a heading always exceeds space below it, so the heading reads as belonging to the text that follows.

A third-level heading

Third level is the last size step. It carries a subsection inside a section, and it is the deepest level worth using in most documents.

A fourth-level heading

Fourth level is set at text size in a heavier weight. It behaves as a label on a paragraph rather than a structural division, which is what most authors actually mean when they reach for it.

A fifth-level heading

Fifth level goes to italic at text size. Notice that it still reads as a heading despite being no larger than the body text — weight and slope carry the signal, size is not needed.

A sixth-level heading

Sixth level is small caps in the muted ink. If a document needs this level, it probably needs restructuring instead, but the component exists so that it never falls back to something worse.

Running text, emphasis and links

Text is set with bold at 650 rather than 700, because most variable text faces get muddy at full bold in running copy, and with italic from the real italic, never a synthesised slant. Struck text drops to the muted ink so that the strike reads as a state and not as damage. Inline code such as --md-measure sits in the mono face at 0.875em, which is the ratio at which a mono cap-height matches a serif x-height closely enough not to jump.

Links are underlined at 0.075em with a 0.16em offset and ink-skip enabled, so descenders stay legible. The underline is the spot colour at 55% opacity, and it resolves to full spot on hover — colour is the hover state, the underline is the affordance. Keys render as ⌘K, and abbreviations like TDC take a dotted underline.

Lists

Ordered markers use tabular lining figures and hang outside the text block, so the left text edge stays true and 9. aligns with 10. — which is the single most common failure in default markdown lists.

Unordered lists step from disc to en dash to middle dot, so nesting reads at a glance:

  • Top level takes a disc.
  • Second item, with children:
    • An en dash marks the second level.
    • Second sibling:
      • A middle dot marks the third.
  • Third top-level item.

A loose list — one where the source left blank lines between items — gets fuller leading automatically, because the generator wraps each item in a paragraph and the stylesheet keys off that:

  • This item is a paragraph, so it receives the loose treatment.

  • So does this one. The spacing between items opens up to half the rhythm unit without any class being added.

Task lists pull the control into the margin so the text edge is unaffected:

  • Marker sits in the hanging indent
  • Completed items drop to muted ink
  • Open items stay at full contrast

Definition lists are the most under-used block in Markdown and the cleanest way to set a glossary, an options reference or a metadata header:

Satzspiegel
The type area: the block of set text on the page, and its relationship to the four margins. The first thing a book jury looks at.
Measure
Line length, counted in characters. Under 80 for sans, a little more permitted for serif.
Optical size
A variable-font axis that adjusts stroke contrast and spacing for the size at which type is set. Present in Literata and in most 2025–26 award-winning families.

Tables

This is the largest gap between award-standard setting and default markdown rendering. The rules are all editorial: no vertical rules ever, three horizontal hairlines at most, no zebra striping by default, tabular figures in numeric columns, and the caption above the table rather than below.

Alerts

Boxes are the least book-like device Markdown has, so they earn their weight through a single vertical rule and a label rather than a filled card with an icon.

Note

The alert tone is a single custom property, so a project can add its own severities without touching the component.

Warning

Justified setting is available but off by default. Turn it on only where hyphenation is active — unhyphenated justification is what juries penalise, not justification itself.

Caution

Six heading levels plus zebra striping plus filled alert cards plus a syntax palette of twelve colours is not a hierarchy. It is noise wearing a hierarchy's clothes.

Code

The code module is a separate stylesheet. Toggle it off in the bar above and fenced blocks fall back to a quiet set block in the mono face bounded by hairlines — which is how a book would set them, and is often the better choice for documents where the code is illustrative rather than operational.

markdown.csscss
/* one measure, resolved once, at body size */.md {  padding-inline: max(2ch, calc((100% - var(--md-measure)) / 2));}.md > pre { margin-inline: calc(var(--md-bleed) * -1); }

An unlabelled, unnumbered block is the default shape, and the one most documents should use:

const rhythm = (leading, size) => leading * size;
// every vertical space is a multiple of one unit
rhythm(1.62, 19); // → 30.78

Footnotes

Footnote references are set in the spot colour with tabular figures and no underline, so they read as apparatus rather than as links.1 The note block itself is separated by a hairline, dropped a step in size, and set in the muted ink.2
